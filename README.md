# Tip Calculator

A tiny single-page tip calculator built with Cursor for MLH Global Hack Week: Hacktoberfest Challenge 1.

Open `index.html` in a browser. Enter the bill, pick a tip percent, optionally split between people, and toggle light/dark mode.

## Run

```bash
open index.html
# or serve locally:
python3 -m http.server 8080 --directory .
```
